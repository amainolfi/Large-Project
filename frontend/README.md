# MacroVanta web client

React 19, TypeScript, and Vite client for the MacroVanta Express JSON API.

```powershell
npm install
npm run dev
```

Set `VITE_API_URL` to the API origin. This is a public build-time value; never
place API keys or other secrets in it. Quality checks are `npm run lint` and
`npm run build`. Full architecture and deployment notes are in the repository
root `README.md`.
